SavingsAccount:
* apply_interest - расчет процентов на текущий баланс, где rate - ставка в процентах (7 для 7%)
* withdraw - переопределение метода снятия. Можно снимать не более 50% от текущего баланса (коэф. 0.5)

Account:
* deposit - метод для пополнения счета
* withdraw - метод для снятия средств
* get_balance - текущий баланс
* get_history - метод, возвращающий историю операций
* plot_history - создание датафрейма из истории операций
* validate_name - валидация имени пользователя
* add_operation - новая операция

Протестировать:
* Возможность создания счета
* Пополнение баланса
* Непополнение отрицательной суммой
* Снятие средств
* Неснятие большей суммы, чем та, что есть на счете
* Получение истории операций
* Пополнение и снятие на сберегательном счете
* Попытку снять больше 50%
* Последние 2 крупные операции
